Setup Guide
ZKTeco / iClock (TCP/IP)

1. Add device here to get an API key.
2. Download zk_bridge.py from the server.
3. Run: DEVICE_API_KEY=xxx ZK_DEVICE_IP=192.168.1.x python zk_bridge.py
4. Punches stream automatically every 30 seconds.

HTTP Push (Suprema / Hikvision)

Configure the device's webhook to POST to:
/api/v1/punch
with header X-Device-Key: <your_key> and JSON body: {"employee_id":"…","punch_time":"…","direction":"in"}

CSV Import (any device)

Export attendance log from your device software. Required columns: employee_id, punch_time (YYYY-MM-DD HH:MM:SS). Optional: employee_name, direction. Click ↑ Import CSV in the Today's Attendance card.

UAE Document Requirements
Visa / Entry Permit

UAE Labour Law requires valid entry permit for all expatriate employees. Alert HR 90 and 30 days before expiry.

Emirates ID (EID)

Federal Identity Authority mandatory. System alerts at 60-day and 30-day pre-expiry milestones.

Passport

Most UAE contracts require 6+ months passport validity. Alert triggered when less than 6 months remain.

Labor Card / Work Permit

MOL Work Permit must be renewed before expiry. Linked to employment contract validity.
